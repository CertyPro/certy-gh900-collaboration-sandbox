# Getting started

A quick orientation for your first contribution to this sandbox.

## What is a fork?

A **fork** is your own copy of someone else's repository under your account. You
can change your fork freely, then propose those changes back to the original with a
**pull request**.

## What is a pull request?

A **pull request** asks the maintainers of the original repository to pull in the
changes from your branch. It is where review and discussion happen before a change
is merged.

## The short version

1. Fork this repository.
2. Create a branch in your fork.
3. Make a small change.
4. Push the branch.
5. Open a pull request back to this repository.
6. Respond to review and get merged.

## Tips for a smooth first contribution

- Keep it small. One change per pull request.
- Read `CONTRIBUTING.md` before you start.
- Link the issue you are solving with `Closes #n`.
- If you are unsure, open a Discussion and ask.

Welcome aboard, and well done for getting hands-on.
