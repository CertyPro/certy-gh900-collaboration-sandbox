# Good first issues

New here? Start with one of the open issues labelled **`good first issue`**:

https://github.com/CertyPro/certy-gh900-collaboration-sandbox/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22

Each one is small, self-contained, and designed to be your first pull request.
Typical first issues include:

- Add yourself to `CONTRIBUTORS.md`.
- Fix a small typo in the documentation.
- Add a beginner-friendly tip to `docs/getting-started.md`.

Pick one, comment that you would like to take it so two people do not duplicate
work, then follow [CONTRIBUTING.md](../CONTRIBUTING.md).
