# GH-900 Collaboration Sandbox

A safe, friendly place to make your **first real open-source contribution**, by
[Certy](https://github.com/CertyPro).

This repository exists so GitHub Foundations (GH-900) learners can practise the
full community workflow: **fork, branch, commit, open a pull request, respond to
review, and get merged**. Everyone is welcome, and a first attempt is exactly what
this repo is for.

## Your contribution exercise

Add yourself to the contributors list:

1. **Fork** this repository (the **Fork** button, top right).
2. Read [CONTRIBUTING.md](CONTRIBUTING.md) and the
   [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
3. Pick a [good first issue](https://github.com/CertyPro/certy-gh900-collaboration-sandbox/issues)
   (look for the `good first issue` label).
4. On a new branch in your fork, add a line about yourself to
   [CONTRIBUTORS.md](CONTRIBUTORS.md).
5. Open a **pull request** back to this repository. Reference the issue you picked,
   for example `Closes #2`.
6. A maintainer will review it. Respond to any comments, then watch it merge.

That is a complete contribution, from fork to merge. It maps directly to exam
domains **3.0 Collaborate using GitHub** and **7.0 Explore the GitHub community**.

## House rules

- Be kind and patient. Everyone here is learning.
- One small change per pull request keeps reviews easy.
- Only edit the files an issue asks you to.
- Have a question? Open a **Discussion** rather than an issue.
